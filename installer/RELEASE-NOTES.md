Prima release distribuibile di Segretario MMG, versione 0.16.0.

- Installer Windows x64 con scelta modello basata sulla RAM.
- Ollama locale, think:false, origine limitata all'ID stabile dell'estensione.
- PDF e OCR inclusi; verifica guidata e istruzioni per Chrome.
- Aggiornamenti automatici dalle release GitHub, rinviati con Chrome aperto.
- Selettore dei modelli locali nell'estensione.

Build pilota non firmata digitalmente. Test automatici e controlli di integrita superati; installazione completa e aggiornamento su Windows pulito ancora da collaudare prima della distribuzione generale. Chiudere Chrome prima di eseguire il setup. Se presente una vecchia estensione senza ID stabile, disattivarla prima di aggiungere quella nuova.

Scaricare l'EXE per installare. segretario-mmg-update.zip e destinato all'updater; gli archivi Source code generati da GitHub non sono installer.
